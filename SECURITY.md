# Security Policy

## Supported Versions

TeamFlow is currently under active development. Security fixes will be applied to the current development version.

## Reporting a Vulnerability

Please report security vulnerabilities privately through the GitHub repository's Security tab using the vulnerability reporting option, if available.

Do not disclose vulnerabilities publicly before the maintainers have had an opportunity to investigate.

Include the following information where possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Relevant logs or screenshots, with secrets and personal data removed

Please do not include passwords, access tokens, API keys, or other secrets in reports.
