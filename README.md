# TeamFlow

![TeamFlow Repository Checks](https://github.com/mittapallikishore/TeamFlow/actions/workflows/ci.yml/badge.svg?branch=main)

TeamFlow is planned as a full-stack application using Django (backend) and React (frontend).

## Current project status

Application development has not started yet. The repository currently contains the initial DevOps foundation:

- Shared GitHub repository and folder structure
- Contribution and Git workflow guidelines
- Backend and frontend environment templates
- Local development setup documentation
- Basic GitHub Actions repository checks

## Repository structure

- `backend/` - Django backend application (planned)
- `frontend/` - React frontend application (planned)
- `docs/` - Setup and workflow documentation
- `.github/workflows/` - CI workflows

## Getting started

Read these documents before contributing:

1. [Contribution Guidelines](CONTRIBUTING.md)
2. [Local Setup Guide](docs/SETUP.md)
3. [Git Workflow](docs/GIT_WORKFLOW.md)

Application-specific setup commands will become executable after the backend and frontend source code and dependency files are added.

## Security

Never commit real `.env` files, credentials, API keys, or access tokens. Use the provided `.env.example` files as safe templates.
